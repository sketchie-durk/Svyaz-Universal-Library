# Svyaz Roadmap: The Path to Total Connectivity

## Phase 1: Foundation (Current)
- [x] Svyaz-ABI Specification.
- [x] Core Implementation in Rust.
- [x] Initial Projector Design.

## Phase 2: The Generator (Upcoming)
- [ ] Implementation of the Svyaz-IDL Compiler.
- [ ] Development of the Universal Projector Generator (UPG).
- [ ] Support for Tier 1 Languages (Rust, C++, Zig).

## Phase 3: Expansion
- [ ] Support for Tier 2 Languages (Go, Java, Swift).
- [ ] Support for Tier 3 Languages (Python, JS, Lua).
- [ ] Integration of the WASM-Sandboxed Core for maximum isolation.

## Phase 4: The Universal Fabric
- [ ] Distributed Svyaz: Projecting modules across a network (Svyaz-RPC).
- [ ] Hot-Reloading: Updating Core logic without restarting Projectors.
- [ ] Auto-Tuning: The Core optimizes its memory layout based on Projector usage patterns.
